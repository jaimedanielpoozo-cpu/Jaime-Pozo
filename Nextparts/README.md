# Jack -- 3D Creator

A 3D Creator portfolio landing page built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Stack

- React + TypeScript (Vite)
- Tailwind CSS
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
